# Pabrews Cafe

A QR-based onsite ordering and management system for Pabrews Cafe.

## Project Goal

The system is designed to make onsite ordering easier for customers and
order management easier for staff and administrators.

## Main Features

- Customer ordering
- Dine-in and takeout orders
- QR-based table ordering
- Product customization
- Shopping cart and checkout
- Order tracking
- Staff order management
- Customer accounts and guest ordering
- Loyalty and rewards
- Menu management
- Inventory management
- Sales and activity records

## Development Approach

This project is being developed incrementally.

The goal is to understand the system, write and review the code,
test each feature, and improve the project step by step.
